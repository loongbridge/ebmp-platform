# 企业商业管理平台（EBMP）接口文档

> 版本：v1.0 ｜ 更新日期：2026-11-02
> 后端：Spring Boot 3.2.5 ｜ 基础路径：`http://<host>:8080`（前端开发态经 Vite 代理 `/api`）

---

## 一、通用约定

### 1.1 请求约定

| 项 | 说明 |
| --- | --- |
| 基础路径 | 所有业务接口以 `/api` 开头 |
| 内容类型 | `application/json; charset=UTF-8`（文件上传为 `multipart/form-data`） |
| 鉴权头 | `Authorization: Bearer <token>` |
| 时间格式 | `LocalDateTime` 使用 ISO `YYYY-MM-DDTHH:mm:ss`；`LocalDate` 使用 `YYYY-MM-DD` |
| 金额 | 数值型（BigDecimal），单位为元 |

### 1.2 统一响应包

```json
{ "code": 0, "message": "ok", "data": { } }
```

| 字段 | 说明 |
| --- | --- |
| `code` | 0 成功；非 0 失败（401 未登录/过期，403 无权限，其余为业务错误） |
| `message` | 提示信息 |
| `data` | 业务数据，可能为对象、数组或 `null` |

### 1.3 分页结构

```json
{ "content": [], "total": 123, "page": 1, "size": 10 }
```

分页接口入参统一为 `page`（从 1 开始）、`size`。

### 1.4 鉴权失败响应

```json
{ "code": 401, "message": "登录已过期，请重新登录", "data": null }
{ "code": 403, "message": "无权限执行该操作", "data": null }
```

### 1.5 公开接口

`POST /api/auth/login`、`GET /api/health`、`GET /uploads/**` 无需 token。

## 二、认证 `/api/auth`

| 方法 | 路径 | 说明 | 请求体 |
| --- | --- | --- | --- |
| POST | `/api/auth/login` | 登录，返回 token 与用户信息 | `{ "username": "admin", "password": "Admin@123" }` |
| GET | `/api/auth/me` | 获取当前登录用户（含角色、权限码） | - |
| POST | `/api/auth/logout` | 退出登录（前端清理 token 即可） | - |

登录响应 `data` 示例：

```json
{
  "token": "eyJhbGciOiJIUzI1NiJ9...",
  "user": {
    "id": 1,
    "username": "admin",
    "realName": "系统管理员",
    "deptId": 1,
    "deptName": "总部",
    "roleCodes": ["ADMIN"],
    "roleNames": ["系统管理员"],
    "permissions": ["dashboard:view", "oa:view", "crm:view", "srm:view", "erp:view", "workflow:approve", "system:view"]
  }
}
```

调用示例：

```bash
curl -X POST http://localhost:8080/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"Admin@123"}'
```

## 十一、审批引擎 `/api/workflow`

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/workflow/approvals?module=&status=&mine=` | 审批单分页/筛选列表 |
| GET | `/api/workflow/approvals/{id}` | 审批详情（含 `nodes` 节点流转） |
| POST | `/api/workflow/approvals/{id}/approve` | 通过，body `{ "comment": "同意" }` |
| POST | `/api/workflow/approvals/{id}/reject` | 驳回，body `{ "comment": "金额需调整" }` |
| GET | `/api/workflow/todo` | 我的待审批列表 |
| GET | `/api/workflow/stats` | 审批统计 |

审批单字段：`module/bizType/bizId/bizNo/title/applicantName/amount/currentStep/totalSteps/currentNodeName/status/nodes[]`。

节点字段：`stepNo/nodeName/approverName/status/comment/actedAt`。

审批规则：

1. 部门负责人为第一级审批人（与申请人相同则跳过）。
2. 金额 ≥ 50000 或 `bizType=CONTRACT` 时追加总经理节点。
3. 同一单据存在 `PENDING` 审批时禁止重复提交。
4. 仅当前节点审批人（或管理员）可操作。

## 十二、文件上传 `/api/files`

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/files/upload` | 上传文件（`multipart/form-data`，字段名 `file`，上限 50MB） |

响应：

```json
{ "name": "员工手册.pdf", "url": "/uploads/9f1c2d....pdf", "size": 102400 }
```

上传后通过 `GET /uploads/{stored}` 匿名访问。

调用示例：

```bash
curl -X POST http://localhost:8080/api/files/upload \
  -H "Authorization: Bearer $TOKEN" \
  -F "file=@./员工手册.pdf"
```
